# Build Instructions

## Scaffold

```bash
npm create vite@latest pwa-location-game -- --template react-ts
cd pwa-location-game
```

## Install

```bash
npm install
npm install maplibre-gl vite-plugin-pwa
```

## Run (Dev)

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
